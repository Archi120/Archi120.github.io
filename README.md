# Archita Lahiri — Personal website

A responsive, static portfolio based on the supplied CV. Built with HTML, CSS, and JavaScript, with no build step. Includes research, projects, education, achievements, contact links, and a downloadable CV.

## Preview

Run `python -m http.server 8000` in this directory and open http://localhost:8000.

## Edit

Update content in `index.html`, appearance in `site.css`, and navigation behavior in `script.js`. Public assets are in `assets/`. Original source photo and CV are excluded from Git; the optimized portrait and downloadable CV are included.

## GitHub Pages

Publish the repository's `main` branch, root folder, with GitHub Pages. All asset paths are relative and work on both account and project sites. The `.nojekyll` file enables plain static serving. No secrets, backend, or dependency installation are required.

The Google Fonts stylesheet has system fallbacks if unavailable.
